# Ask Practice

Bring a real problem, not a vague request for the best AI tool.

## Strong question template

- **Outcome:** What needs to be true afterward?
- **Current process:** How does the work happen now?
- **Inputs:** What information or systems are available?
- **Constraints:** Security, cost, time, policy, or human-review requirements.
- **Failure:** What would make the result unusable or dangerous?
- **Evidence:** What have you already tried?

Useful answers should be distilled into a Note, Practice, Guide change, Lab, Story, or Project.
