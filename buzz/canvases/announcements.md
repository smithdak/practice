# Announcements

Find approved updates that change what the community should know or do. This
stream stays low-volume so a Practitioner can scan it without reconstructing a
working discussion.

## Every announcement answers

- **What changed?** Name the exact artifact, release, Session, or operating rule.
- **Who does it affect?** Name the intended Practitioner or contributor.
- **Where is the durable record?** Link the canonical Git artifact or release.
- **What happens next?** Give one action, or say that no action is required.

## Post only when it is ready

- A human owner has approved the update for publication.
- The durable artifact exists and the link has been checked.
- Evidence limits and effective dates are stated when they matter.

Drafts, questions, repeated activity updates, and model-news summaries belong
in the relevant working channel. Continue discussion there rather than turning
this stream into a second copy of the work.

### Example (hypothetical)

> **Guide update:** The context-engineering module now links one canonical
> worksheet instead of repeating it. This helps Practitioners following the
> Guide. Inspect the updated module in Git; no other action is required.
