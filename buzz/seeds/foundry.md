# Build command center

Post one line when work changes state:

`TASK_ID · ACTIVE|BLOCKED|REVIEW|DONE · next action or blocker · branch`

Put durable artifacts in Git. Put a decision, dependency, or blocker here only when someone needs to act on it. Never paste keys, credentials, or client-confidential material. If a decision needs owner approval, say what choice is needed and link the relevant Git artifact.
