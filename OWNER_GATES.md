# Owner Gates

The swarm should continue using the defaults below. These are the only items that require Dakota's direct action or explicit approval before public launch.

| Gate | Needed for | Default | Blocks agent work? |
|---|---|---|---|
| Buzz community address and relay URL | Applying the Buzz bootstrap | Create a Block-hosted `practice` community or closest available address | No; use dry run |
| Owner identity backup | Secure community administration | Back up the Buzz identity offline before inviting others | No |
| GitHub destination | Publishing canonical artifacts | `smithdak/practice` if available | No; build locally |
| License confirmation | Final publication | Apache-2.0 for code; CC BY 4.0 for content | No |
| Public invitation path | Opening membership | Buzz invite link routed from public Git README/social profiles | No |
| Initial community-agent providers | Starting runtime agents | Start with three agents; select low-cost models manually | No |
| Launch date | Coordinated publishing | Leave unset until release validation passes | No |
| Brand mark | Visual identity | Text-only wordmark for launch | No |

## Manual actions never delegated

- creating or recovering the owner Buzz identity;
- storing or entering the owner private key;
- approving final moderation actions;
- accepting licensing and governance changes;
- publishing the final launch announcement;
- adding billing credentials or provider secrets.
