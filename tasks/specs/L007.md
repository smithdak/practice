- **Wave:** 4
- **Lane:** operations
- **Recommended model tier:** cheap
- **Mode:** build
- **Dependencies:** L005

## Objective

Create a sustainable founder-plus-agents cadence that compounds artifacts rather than producing constant channel activity.

## Read

- `AGENTS.md`
- `CONTEXT.md`
- `DECISIONS.md`
- `NON_GOALS.md`
- `QUALITY_BAR.md`

## Owned outputs

- `ops/WEEKLY_CADENCE.md`
- `handoffs/L007.md`

## Scope rule

Modify only the owned output paths and the handoff file.

## Requirements

- Define intake, build, review, release, Session, and maintenance cycles.
- Separate continuous queues from scheduled review.
- Show which agent prepares each packet and which human approves.

## Acceptance

- [ ] No ceremony without an output.
- [ ] Cadence can operate with a small community.
- [ ] Includes a low-activity fallback.
- [ ] `python3 scripts/validate.py --task L007 --root .` passes.
- [ ] `handoffs/L007.md` records status, validation, decisions, risks, and deferred opportunities.
- [ ] The worktree is committed and clean.

## Stop conditions

Stop and write a `BLOCKED` handoff rather than guessing when a locked decision conflicts with this task, a current claim cannot be verified, required evidence is unavailable, or completing the task requires editing an unowned path.
