- **Wave:** 4
- **Lane:** operations
- **Recommended model tier:** balanced
- **Mode:** build
- **Dependencies:** B002, K001

## Objective

Create a repeatable live Workflow Clinic that produces a reusable Practice artifact.

## Read

- `AGENTS.md`
- `CONTEXT.md`
- `DECISIONS.md`
- `NON_GOALS.md`
- `QUALITY_BAR.md`

## Owned outputs

- `ops/FIRST_PRACTICE_SESSION.md`
- `handoffs/L004.md`

## Scope rule

Modify only the owned output paths and the handoff file.

## Requirements

- Define participant intake, selection, preparation, facilitation, artifact capture, consent, follow-up, and publication review.
- Include roles for host, Steward, Librarian, and Research Auditor.
- Include contingency paths when the workflow is sensitive or unsuitable.

## Acceptance

- [ ] Session produces a concrete draft artifact.
- [ ] No private data is exposed by default.
- [ ] Participants can decline publication.
- [ ] `python3 scripts/validate.py --task L004 --root .` passes.
- [ ] `handoffs/L004.md` records status, validation, decisions, risks, and deferred opportunities.
- [ ] The worktree is committed and clean.

## Stop conditions

Stop and write a `BLOCKED` handoff rather than guessing when a locked decision conflicts with this task, a current claim cannot be verified, required evidence is unavailable, or completing the task requires editing an unowned path.
