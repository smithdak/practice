# Q005 — Integrate review findings and prepare final release

- **Wave:** 5
- **Lane:** integration
- **Recommended model tier:** strong
- **Mode:** integration
- **Dependencies:** Q001, Q002, Q003, Q004, L008

## Objective

Apply blocking review findings across the repository, reconcile conflicts, run release validation, and create the final integration report.

## Read

- `AGENTS.md`
- `CONTEXT.md`
- `DECISIONS.md`
- `NON_GOALS.md`
- `QUALITY_BAR.md`

## Owned outputs

- `release/FINAL_INTEGRATION_REPORT.md`
- `handoffs/Q005.md`

## Scope rule

This is the final integration task. You may edit project artifacts to resolve documented review findings, but you may not silently change locked decisions.

## Requirements

- May edit any project artifact except locked decisions unless an owner gate is opened.
- Resolve blocking findings and disposition non-blocking findings.
- Run `python3 scripts/validate.py --release`.
- Update release/OWNER_REVIEW.md with final manual actions.

## Acceptance

- [ ] Release validation passes or the report says BLOCKED with exact evidence.
- [ ] All review findings have a disposition.
- [ ] No owner-only action is falsely marked complete.
- [ ] `python3 scripts/validate.py --task Q005 --root .` passes.
- [ ] `handoffs/Q005.md` records status, validation, decisions, risks, and deferred opportunities.
- [ ] The worktree is committed and clean.

## Stop conditions

Stop and write a `BLOCKED` handoff rather than guessing when a locked decision conflicts with this task, a current claim cannot be verified, required evidence is unavailable, or completing the task requires editing an unowned path.
