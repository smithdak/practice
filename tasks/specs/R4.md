# R4 — License, attribution, and claim re-audit of publishable artifacts

- **Wave:** 6
- **Lane:** knowledge
- **Recommended model tier:** balanced
- **Mode:** review
- **Dependencies:** none

## Objective

Re-audit every publishable artifact for unlicensed content, missing attribution, and unsupported claims.

## Read

- `AGENTS.md`
- `CONTEXT.md`
- `DECISIONS.md`
- `NON_GOALS.md`
- `QUALITY_BAR.md`

## Owned outputs

- `research/CLAIM_AUDIT.md`
- `handoffs/R4.md`

## Scope rule

This is a review task. Do not edit the artifacts under review; write only the report and handoff.

## Requirements

- Sweep all publishable artifacts for license and attribution defects.
- Record findings as a checklist, not as prose.
- Name the exact file and location for each finding.

## Acceptance

- [ ] Zero unlicensed or unattributed items remain unrecorded.
- [ ] Findings are a checklist a human can work through item by item.
- [ ] Each item states the file, the defect class, and the correction.
- [ ] `python3 scripts/validate.py --task R4 --root .` passes.
- [ ] `handoffs/R4.md` records status, validation, decisions, risks, and deferred opportunities.
- [ ] The worktree is committed and clean.

## Stop conditions

Stop and write a `BLOCKED` handoff rather than guessing when a locked decision conflicts with this task, a current claim cannot be verified, required evidence is unavailable, or completing the task requires editing an unowned path.
