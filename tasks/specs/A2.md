# A2 — Link checker and as-of-date linter

- **Wave:** 6
- **Lane:** foundation
- **Recommended model tier:** code
- **Mode:** build
- **Dependencies:** none

## Objective

Detect broken relative links and stale as-of dates across all committed markdown.

## Read

- `AGENTS.md`
- `CONTEXT.md`
- `DECISIONS.md`
- `NON_GOALS.md`
- `QUALITY_BAR.md`

## Owned outputs

- `scripts/check_links.py`
- `tests/test_check_links.py`
- `handoffs/A2.md`

## Scope rule

This is a build task. Change only the owned outputs and the handoff.

## Requirements

- Resolve every relative markdown link and report broken targets.
- Report as-of dates older than the current snapshot date.
- Run offline and deterministically; make no network requests.
- Ship unit tests for both check classes.

## Acceptance

- [ ] Broken links and stale as-of dates are both reported with file and line.
- [ ] The checker makes no network requests.
- [ ] Unit tests cover both check classes.
- [ ] `python3 scripts/validate.py --task A2 --root .` passes.
- [ ] `handoffs/A2.md` records status, validation, decisions, risks, and deferred opportunities.
- [ ] The worktree is committed and clean.

## Stop conditions

Stop and write a `BLOCKED` handoff rather than guessing when a locked decision conflicts with this task, a current claim cannot be verified, required evidence is unavailable, or completing the task requires editing an unowned path.
