- **Wave:** 11
- **Lane:** operations
- **Recommended model tier:** balanced

## Objective

Define what each autonomy level means, what evidence raises one, what demotes one, and which operations may never be automated.

## Scope rule

This is a build task. Change only the owned outputs and the handoff.

## Requirements

- Reuse the vocabulary the registry and the packet schema already spell.
- State demotion triggers as observable events, never judgment calls.
- List every operation permanently ineligible for unattended action with the decision that makes it so.
- Map every registered agent and every cadence operation to a level.

- [ ] Nothing in the repository is mapped to the unattended level.
- [ ] Adding an agent or a cadence pass without updating the mapping fails the test.
- [ ] The parser fails loudly on a missing section rather than passing vacuously.
- [ ] `python3 scripts/validate.py --task S3 --root .` passes.
- [ ] `handoffs/S3.md` records status, validation, decisions, risks, and deferred opportunities.
- [ ] The worktree is committed and clean.

## Stop conditions

Stop and write a `BLOCKED` handoff rather than guessing when a locked decision conflicts with this task, a current claim cannot be verified, required evidence is unavailable, or completing the task requires editing an unowned path.
