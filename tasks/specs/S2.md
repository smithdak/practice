# S2 — Agent output packet contract

- **Wave:** 10
- **Lane:** operations
- **Recommended model tier:** balanced
- **Mode:** build
- **Dependencies:** none

## Objective

Turn the bounded packet every agent profile promises into a schema a validator can check.

## Read

- `AGENTS.md`
- `CONTEXT.md`
- `DECISIONS.md`
- `NON_GOALS.md`
- `QUALITY_BAR.md`

## Owned outputs

- `docs/schemas/AGENT_PACKET_SCHEMA.md`
- `templates/AGENT_PACKET.md`
- `scripts/validate_packet.py`
- `tests/test_validate_packet.py`
- `handoffs/S2.md`

## Scope rule

This is a build task. Change only the owned outputs and the handoff.

## Requirements

- Record provenance and a trust level for every input.
- Require a pointer or a dated source on every evidence claim.
- Require a refusals section and fix `human_decision_required` true.
- Constrain `decision_owner` to a controlled role vocabulary so a personal name cannot be recorded.

## Acceptance

- [ ] A packet asserting a promotion, a maturity change, or a cleared gate fails validation.
- [ ] The worked example is labeled hypothetical and validates against its own rules.
- [ ] Unit tests cover every rejection path.
- [ ] `python3 scripts/validate.py --task S2 --root .` passes.
- [ ] `handoffs/S2.md` records status, validation, decisions, risks, and deferred opportunities.
- [ ] The worktree is committed and clean.

## Stop conditions

Stop and write a `BLOCKED` handoff rather than guessing when a locked decision conflicts with this task, a current claim cannot be verified, required evidence is unavailable, or completing the task requires editing an unowned path.
