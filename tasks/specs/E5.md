# E5 — Assemble per-candidate promotion packets

- **Wave:** 7
- **Lane:** release
- **Recommended model tier:** balanced
- **Mode:** build
- **Dependencies:** E1, E2, E3, E4

## Objective

Package the trial evidence, reviewer notes, and the exact human decision for each method candidate.

## Read

- `AGENTS.md`
- `CONTEXT.md`
- `DECISIONS.md`
- `NON_GOALS.md`
- `QUALITY_BAR.md`

## Owned outputs

- `release/PROMOTION_PACKETS.md`
- `handoffs/E5.md`

## Scope rule

This is a build task. Change only the owned outputs and the handoff.

## Requirements

- Give each candidate a criteria checklist scored against its schema.
- State the residual risks and the exact decision question per candidate.
- List the exact edits a promotion would require.
- Never flip `maturity` or `evidence_quality`; package the decision only.

## Acceptance

- [ ] Each packet states its decision question and the edits a promotion requires.
- [ ] Agent recommendations are labeled non-binding.
- [ ] No maturity or evidence-quality field is changed by this task.
- [ ] `python3 scripts/validate.py --task E5 --root .` passes.
- [ ] `handoffs/E5.md` records status, validation, decisions, risks, and deferred opportunities.
- [ ] The worktree is committed and clean.

## Stop conditions

Stop and write a `BLOCKED` handoff rather than guessing when a locked decision conflicts with this task, a current claim cannot be verified, required evidence is unavailable, or completing the task requires editing an unowned path.
