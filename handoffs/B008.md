# B008 Handoff

## Status

COMPLETE

## Summary

Expanded `buzz/agents/LIBRARIAN.md` into a deployable, review-only profile for
turning eligible community work into candidate Practice artifacts. It defines
classification rules for all core artifact types, requires source-thread links
and permission-aware attribution, preserves disagreement, blocks private
material by default, maps outputs to canonical templates, and includes an
operational workflow, escalation contract, access boundaries, and eight
evaluation scenarios.

## Files changed

- `buzz/agents/LIBRARIAN.md`
- `handoffs/B008.md`

## Validation

- Command: `python3 scripts/validate.py --task B008 --root .`
- Result: Passed.

## Decisions made

- Used the repository's existing artifact vocabulary: Practice, Guide, Lab,
  Story, Note, Project, Issue, and Decision.
- Required `source_threads` in every review packet and prohibited invented
  links when a stable source URL is unavailable.
- Set the default evidence posture to source-bounded and left missing evidence
  as `unknown`, `none`, or `not measured` rather than inferring outcomes.
- Made every output explicitly `DRAFT — HUMAN REVIEW REQUIRED`; the identity
  has no merge, publication, moderation, or owner privilege.

## Risks or unresolved questions

- Buzz's concrete stable-thread URL format and contributor-consent mechanism
  are not specified in the available task inputs; the profile therefore
  requires an inspectable link and explicit permission without asserting a
  platform-specific workflow.
- Note, Project, Issue, and Decision do not have canonical repository templates
  in the available inputs, so their packet shape is described without
  pretending a missing schema exists.

## Deferred opportunities

- Define and publish dedicated schemas/templates for Note, Project, Issue, and
  Decision artifacts.
- Add a human-maintainer review checklist or repository automation for checking
  source links, consent, and template conformance.
