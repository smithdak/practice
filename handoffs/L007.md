## Summary

Created a founder-plus-agents weekly operating cadence organized around
continuous queues and scheduled review passes. It defines intake, build,
review, release, Session, and maintenance cycles; names the approved agent
profiles preparing each packet and the human decision at each boundary; and
includes a low-activity fallback for a small community.

## Decisions made

- Used queue-based work and explicit outputs rather than standing meetings or
  required channel activity.
- Kept Buzz as the working/routing hub and Git as the durable record; the
  cadence does not depend on scheduled Buzz workflows.
- Assigned agents preparation and checking only. Human maintainers retain
  merge, publication, Session consent, moderation, release, and reserved
  access decisions.
- Made release and Session conditional on a ready packet and concrete output,
  with a two-week/on-next-available-pass fallback for low activity.
- Mapped packet preparation to the approved Practice Steward, Practice
  Librarian, Guide Maintainer, Research Auditor, and Release Editor profiles;
  build remains assigned to a bounded task-specific construction agent.
- Used `deprecate` for stale artifacts so history is preserved.
