## Summary

Replaced the minimal Guide Maintainer profile with a deployable, review-only
operating contract. It now covers change detection, primary-source
verification for changing technical claims, distinct staleness/deprecation
classification, version recommendations, escalation, and a structured human
review packet. Seven evaluation scenarios exercise the boundaries.

## Decisions made

- Kept the locked `Learn → Use → Automate → Build → Transform` capability
  ladder immutable to this agent; taxonomy changes escalate to an owner.
- Defined staleness as possible currency drift and deprecation as authoritative
  retirement/supersession; age alone cannot establish deprecation.
- Made version changes recommendations in a review packet, not autonomous
  edits, and used patch/minor/major guidance tied to reader-visible impact.
- Required source URL/path plus title and as-of date for changing technical
  claims, with primary-source verification.

## Risks or unresolved questions

- The repository does not prescribe a guide versioning scheme; the profile
  explicitly labels semantic-like versioning as a recommendation and defers a
  stricter scheme to the repository owner.
- A current claim with no accessible primary source remains `unverified` and
  requires human review rather than a guessed update.
