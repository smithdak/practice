## Decisions made

- Comparison set pinned to R4's 68 audited files even though the checker's live corpus enumeration found 69 by run T4: worker E3 created `labs/004-verification-gate-trial.md` concurrently between runs; the seventh file is clean on both classes but sits outside R4's reference set, so it is recorded as an explained inventory delta, not agreement evidence.

This is recorded as the trial's key lesson: the reference comparison caught two false alarms the checker itself believed were findings.
- Masking (fenced blocks + inline code spans) encoded as explicit policy per repository convention (`scripts/check_links.py`, Q004-RI-04); the unmasked sensitivity variant produces a one-file false positive on prose that describes marker words, so the policy is load-bearing and documented in the Lab.
- The published checker takes the repository root from `argv` — the initial version hard-coded a personal path, which would itself violate the audit's class-5 discipline; the personal path was removed before recording.
- The human checkpoint (findings review, exception-list review, publication gate) is specified in the Lab as a design record; no human executed it, and the Lab labels every non-executed element as such.

- Four of six defect classes remain unmechanized and unmeasured; the AI-assisted triage step (classes 1/2/3/5) has no trial, and the live class-5 finding (`README.md:43`) still awaits the owner decision R4 recorded.
