# A2 Handoff

## Status

COMPLETE

## Summary

Added `scripts/check_links.py` (stdlib-only, deterministic, offline) and
`tests/test_check_links.py` (34 unittest cases, tempfile fixtures only). The
checker scans every `.md` file under a root (skipping `.git/`, `.worktrees/`,
`__pycache__/`), extracts inline links (bracketed text followed by a
parenthesised target) and reference-style definitions (a bracketed label, a
colon, then a target), and verifies each relative target exists:
`../` segments resolve, `#anchors` are stripped, percent-encoded targets are
decoded, `<...>`-wrapped targets with spaces are supported, and repo-absolute
`/path` targets resolve against the repo root. External schemes (`http://`,
`https://`, `mailto:`, `buzz://`, any `scheme://`) and fragment-only targets
are skipped. Code fences and inline code spans are masked before scanning so
documented examples are never treated as links. As-of
dates: every `As of:` occurrence (bold variants included) with an ISO
`YYYY-MM-DD` date is parsed; dates older than 90 days produce
`path:line: warning` lines and a summary count, and never affect the exit
code. Failures print `path:line: message` to stderr and exit 1; a clean run
exits 0. `--as-of YYYY-MM-DD` overrides today's date for reproducible runs
(the tests pin it, so the suite is deterministic forever).

## Decisions made

- Mask fenced code blocks and inline code spans before scanning. The repo
  quotes markdown link syntax inside code (e.g. `reviews/REPOSITORY_INTEGRITY.md`,
  `swarm/handoffs/R2.md`); a linter that reads code as prose generates false
  positives. `scripts/validate.py` does not mask and currently fails on
  `swarm/handoffs/R2.md` line 20, where an inline-code placeholder made of an
  ellipsis in brackets followed by an ellipsis in parentheses is read as a
  broken link. That is a validate.py false positive on a
  parallel worker's file, not a broken link; left unmodified per scope.
- Relative links that resolve outside the repo root are errors
  (`link escapes repository`), matching `validate.py`'s existing rule; the
  target cannot work in a fresh checkout even if the file exists locally.
- As-of matching requires a colon (tolerating bold/whitespace variants:
  `As of:`, `As of :`, `**As of:**`), per the task wording; the colon-less
  prose form `As of **2026-08-31**,` in `skills/README.md` is deliberately not
  matched. Dates that are not valid ISO dates (e.g. the `<YYYY-MM-DD>`
  template placeholder) are ignored silently.
- Staleness is measured against today's date by default, with `--as-of` for
  reproducibility; exactly 90 days is not stale, 91 is.
- Directory-name exclusions apply at any depth (`.git`, `.worktrees`,
  `__pycache__`), and output is sorted by path then line for determinism.

## Risks or unresolved questions

- `scripts/validate.py --root .` currently exits 1 for every task because of
  the `swarm/handoffs/R2.md` inline-code false positive described above (R2 owns
  that file; validate.py itself is not in A2 scope). If that failure is
  unacceptable for launch validation, either validate.py needs the same
  code-masking rule or R2's handoff needs the example reworded. Evidence:
  `python3 scripts/validate.py --root .` on 2026-09-01.
- `swarm/manifest.json` has no A-task entries, so `validate.py --task A2`
  reports `Unknown task A2` and task-scoped validation (outputs exist,
  non-empty) cannot run until wiring lands.
- Link targets containing literal parentheses, escaped brackets, or literal
  `%`-sequences in filenames would be mis-parsed; none exist in the repo
  (verified by grep on 2026-09-01).

## Deferred opportunities

- Verify `#anchor` fragments against headings in the target file instead of
  stripping them.
- Check that reference-style link usages (`[text][label]`, `[label][]`) have
  a matching definition (repo currently has none).
- Match colon-less currency claims (`As of **2026-08-31**,`) and other date
  formats; warn on unparseable as-of values and dates in the future.
- Support multi-line reference definitions and link destinations with
  balanced parentheses; report images and reference usages distinctly in the
  summary counts.
- Optional `--check-anchors`/`--strict` flags if CI (A4) wants warnings to
  fail builds.
