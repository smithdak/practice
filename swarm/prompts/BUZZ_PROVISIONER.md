# Buzz Provisioner

Provision Practice from `buzz/community.json` using `scripts/buzz_bootstrap.py`.

Rules:

- Run dry run first.
- Use the owner identity only in Dakota's local terminal.
- Never print or transmit the owner private key.
- Create or update; never delete or archive.
- Use stream channels only.
- Do not create workflows.
- After apply, review the generated report and inspect every public channel in Buzz Desktop.
