## Objective

Create the canonical schema and authoring rules for reusable Practices.

## Scope rule

Modify only the owned output paths and the handoff file.

## Requirements

- Define required and optional metadata.
- Define maturity states from proposed through verified and deprecated.
- Define evidence-quality levels.
- Include a worked classification example.
- Keep author burden proportional to maturity.

## Acceptance

- [ ] Template and schema agree.
- [ ] A validator could be built from the rules.
- [ ] Failure modes and evaluation are required for mature Practices.
- [ ] `python3 scripts/validate.py --task K001 --root .` passes.
- [ ] `swarm/handoffs/K001.md` records status, validation, decisions, risks, and deferred opportunities.
- [ ] The worktree is committed and clean.

## Stop conditions

Stop and write a `BLOCKED` handoff rather than guessing when a locked decision conflicts with this task, a current claim cannot be verified, required evidence is unavailable, or completing the task requires editing an unowned path.
