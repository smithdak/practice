# L005 — Create the maintainer operating runbook

- **Wave:** 4
- **Lane:** operations
- **Recommended model tier:** balanced
- **Mode:** build
- **Dependencies:** F004, F005, B006

## Objective

Define the recurring human and agent work required to keep Practice useful, current, and safe.

## Read

- `AGENTS.md`
- `docs/CONTEXT.md`
- `docs/DECISIONS.md`
- `docs/NON_GOALS.md`
- `docs/QUALITY_BAR.md`

## Owned outputs

- `ops/MAINTAINER_RUNBOOK.md`
- `swarm/handoffs/L005.md`

## Scope rule

Modify only the owned output paths and the handoff file.

## Requirements

- Cover inbox triage, questions, artifact review, agent review, releases, moderation, stale content, backups, and owner gates.
- Define responsibilities and escalation.
- Prefer queues and checklists over meetings.

## Acceptance

- [ ] A maintainer can operate Practice without founder-only tribal knowledge.
- [ ] Agent assistance is bounded and reviewable.
- [ ] Includes failure and recovery procedures.
- [ ] `python3 scripts/validate.py --task L005 --root .` passes.
- [ ] `swarm/handoffs/L005.md` records status, validation, decisions, risks, and deferred opportunities.
- [ ] The worktree is committed and clean.

## Stop conditions

Stop and write a `BLOCKED` handoff rather than guessing when a locked decision conflicts with this task, a current claim cannot be verified, required evidence is unavailable, or completing the task requires editing an unowned path.
