# A4 — GitHub CI wiring

- **Wave:** 6
- **Lane:** foundation
- **Recommended model tier:** code
- **Mode:** build
- **Dependencies:** none

## Objective

Run the unit tests, release validation, and link check on every pull request.

## Read

- `AGENTS.md`
- `docs/CONTEXT.md`
- `docs/DECISIONS.md`
- `docs/NON_GOALS.md`
- `docs/QUALITY_BAR.md`

## Owned outputs

- `.github/workflows/ci.yml`
- `swarm/handoffs/A4.md`

## Scope rule

This is a build task. Change only the owned outputs and the handoff.

## Requirements

- Run `python3 -m unittest discover -s tests`.
- Run `python3 scripts/validate.py --release`.
- Run the link checker.
- Pin the runner and Python version explicitly.

## Acceptance

- [ ] All three checks run on pull request and on pushes to the default branch.
- [ ] The workflow fails the build when any check fails.
- [ ] No secret is required for the workflow to run.
- [ ] `python3 scripts/validate.py --task A4 --root .` passes.
- [ ] `swarm/handoffs/A4.md` records status, validation, decisions, risks, and deferred opportunities.
- [ ] The worktree is committed and clean.

## Stop conditions

Stop and write a `BLOCKED` handoff rather than guessing when a locked decision conflicts with this task, a current claim cannot be verified, required evidence is unavailable, or completing the task requires editing an unowned path.
