# A5 — Reusable non-secret release-evidence record template

- **Wave:** 6
- **Lane:** release
- **Recommended model tier:** cheap
- **Mode:** build
- **Dependencies:** none

## Objective

Give a human a fillable, non-secret record for the evidence gathered at each release.

## Read

- `AGENTS.md`
- `docs/CONTEXT.md`
- `docs/DECISIONS.md`
- `docs/NON_GOALS.md`
- `docs/QUALITY_BAR.md`

## Owned outputs

- `templates/RELEASE_EVIDENCE.md`
- `swarm/handoffs/A5.md`

## Scope rule

This is a build task. Change only the owned outputs and the handoff.

## Requirements

- Provide fields for command, output, date, and operator.
- Contain no secrets, credentials, or participant data.
- State explicitly what must never be recorded in it.

## Acceptance

- [ ] The template is fillable without any tooling.
- [ ] It names the categories of material that must never be pasted into it.
- [ ] It carries no placeholder that could be published unfilled.
- [ ] `python3 scripts/validate.py --task A5 --root .` passes.
- [ ] `swarm/handoffs/A5.md` records status, validation, decisions, risks, and deferred opportunities.
- [ ] The worktree is committed and clean.

## Stop conditions

Stop and write a `BLOCKED` handoff rather than guessing when a locked decision conflicts with this task, a current claim cannot be verified, required evidence is unavailable, or completing the task requires editing an unowned path.
