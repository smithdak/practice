# O2 — Steward escalation readiness checker

- **Wave:** 8
- **Lane:** operations
- **Recommended model tier:** code
- **Mode:** build
- **Dependencies:** none

## Objective

Let a human verify, before enabling the Steward, that a member-actionable human escalation route is configured.

## Read

- `AGENTS.md`
- `docs/CONTEXT.md`
- `docs/DECISIONS.md`
- `docs/NON_GOALS.md`
- `docs/QUALITY_BAR.md`

## Owned outputs

- `scripts/steward_readiness_check.py`
- `swarm/handoffs/O2.md`

## Scope rule

This is a build task. Change only the owned outputs and the handoff.

## Requirements

- Check configuration only; never contact a relay or send a message.
- Fail closed when the escalation reference is missing or unusable.
- Report each prerequisite separately with an actionable message.

## Acceptance

- [ ] The checker exits non-zero when any prerequisite is unmet.
- [ ] It performs no network access.
- [ ] Each unmet prerequisite is reported with the action that would satisfy it.
- [ ] `python3 scripts/validate.py --task O2 --root .` passes.
- [ ] `swarm/handoffs/O2.md` records status, validation, decisions, risks, and deferred opportunities.
- [ ] The worktree is committed and clean.

## Stop conditions

Stop and write a `BLOCKED` handoff rather than guessing when a locked decision conflicts with this task, a current claim cannot be verified, required evidence is unavailable, or completing the task requires editing an unowned path.
