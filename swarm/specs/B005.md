- **Wave:** 2
- **Lane:** buzz

## Objective

Make Buzz setup idempotent, dry-run-first, inspectable, and safe against current platform limitations.

## Scope rule

Modify only the owned output paths and the handoff file.

## Requirements

- Use only the launch-safe CLI surface in the platform snapshot.
- Create missing stream channels, set topic/purpose/canvas, and seed messages once.
- Never delete or archive.
- Redact secrets from errors and reports.
- Handle common JSON response shapes and actionable failures.

## Acceptance

- [ ] Dry run requires no Buzz installation or credentials.
- [ ] Apply requires explicit --apply and environment variables.
- [ ] Re-running apply does not duplicate seed messages when recent history contains the marker.
- [ ] Runbook includes rollback-by-manual-review, not destructive automation.
- [ ] `python3 scripts/validate.py --task B005 --root .` passes.
- [ ] `swarm/handoffs/B005.md` records status, validation, decisions, risks, and deferred opportunities.
- [ ] The worktree is committed and clean.

## Stop conditions

Stop and write a `BLOCKED` handoff rather than guessing when a locked decision conflicts with this task, a current claim cannot be verified, required evidence is unavailable, or completing the task requires editing an unowned path.
