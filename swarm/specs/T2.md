## Requirements

- Implement only the metrics `ops/METRICS.md` says are countable from committed evidence.
- Print every remaining metric as needing the human route, never as a zero.
- Enforce the data-not-to-collect rules in code, not only in prose.
- Produce identical bytes across two runs on the same tree.
