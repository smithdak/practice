# S1 — Machine-readable agent registry and boundary validator

- **Wave:** 10
- **Lane:** buzz
- **Recommended model tier:** code
- **Mode:** build
- **Dependencies:** none

## Objective

Declare each agent profile's identity, channel scope, guardrails, escalation route, and enablement prerequisites in a form a validator can check.

## Read

- `AGENTS.md`
- `docs/CONTEXT.md`
- `docs/DECISIONS.md`
- `docs/NON_GOALS.md`
- `docs/QUALITY_BAR.md`

## Owned outputs

- `buzz/agents/registry.yaml`
- `scripts/validate_agents.py`
- `tests/test_validate_agents.py`
- `swarm/handoffs/S1.md`

## Scope rule

This is a build task. Change only the owned outputs and the handoff.

## Requirements

- Derive every registry entry from its profile text; never grant scope a profile does not state.
- Fail when a declared channel is absent from `buzz/community.json`.
- Fail when a guardrail list drops a locked non-negotiable, or an escalation route names a person rather than a role.
- Fail when an entry claims enabled while owner gate 6 reads OPEN, and fail closed if that gate cannot be anchored.

## Acceptance

- [ ] Every profile has an entry and every entry names an existing profile.
- [ ] No agent declares an unattended autonomy level; every status reads not_enabled.
- [ ] Unit tests cover every enforced failure mode.
- [ ] `python3 scripts/validate.py --task S1 --root .` passes.
- [ ] `swarm/handoffs/S1.md` records status, validation, decisions, risks, and deferred opportunities.
- [ ] The worktree is committed and clean.

## Stop conditions

Stop and write a `BLOCKED` handoff rather than guessing when a locked decision conflicts with this task, a current claim cannot be verified, required evidence is unavailable, or completing the task requires editing an unowned path.
