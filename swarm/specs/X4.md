- **Wave:** 14
- **Lane:** operations
- **Recommended model tier:** code

## Objective

Evaluate the autonomy ladder's observable demotion triggers so a level can go down as well as up.

## Scope rule

This is a build task. Change only the owned outputs and the handoff.

## Requirements

- Parse the triggers from the ladder rather than transcribing a copy that will drift.
- Classify every trigger as evaluable here or not, with a stated reason.
- Detect and report only; removing a promotion stays a human act.
- Fail loudly when the ladder's trigger section is missing rather than reporting zero triggers.

## Acceptance

- [ ] Drift in either direction between the ladder and the classifications fails loudly.
- [ ] An empty ledger exits 0 for the right reason, not a vacuous one.
- [ ] A refused or dry run fires no trigger.
- [ ] `python3 scripts/validate.py --task X4 --root .` passes.
- [ ] `swarm/handoffs/X4.md` records status, validation, decisions, risks, and deferred opportunities.
- [ ] The worktree is committed and clean.

## Stop conditions

Stop and write a `BLOCKED` handoff rather than guessing when a locked decision conflicts with this task, a current claim cannot be verified, required evidence is unavailable, or completing the task requires editing an unowned path.
