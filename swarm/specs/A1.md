# A1 — Schema-aware artifact validators

- **Wave:** 6
- **Lane:** foundation
- **Recommended model tier:** code
- **Mode:** build
- **Dependencies:** none

## Objective

Mechanize the Practice, Guide, Lab, and Story front-matter schemas and the maturity/evidence invariants.

## Read

- `AGENTS.md`
- `docs/CONTEXT.md`
- `docs/DECISIONS.md`
- `docs/NON_GOALS.md`
- `docs/QUALITY_BAR.md`

## Owned outputs

- `scripts/validate_artifacts.py`
- `tests/test_validate_artifacts.py`
- `swarm/handoffs/A1.md`

## Scope rule

This is a build task. Change only the owned outputs and the handoff.

## Requirements

- Validate front matter for every artifact type against its schema.
- Flag any artifact claiming `maturity: tested` without a linked trial record.
- Run offline and deterministically; fail with actionable messages.
- Ship unit tests covering each invariant.

## Acceptance

- [ ] A tested-maturity artifact with no linked trial record fails validation.
- [ ] The validator runs offline and exits non-zero with an actionable message.
- [ ] Unit tests cover every enforced invariant.
- [ ] `python3 scripts/validate.py --task A1 --root .` passes.
- [ ] `swarm/handoffs/A1.md` records status, validation, decisions, risks, and deferred opportunities.
- [ ] The worktree is committed and clean.

## Stop conditions

Stop and write a `BLOCKED` handoff rather than guessing when a locked decision conflicts with this task, a current claim cannot be verified, required evidence is unavailable, or completing the task requires editing an unowned path.
